# 米制视觉小偏差闭环（SITL）

入口：scripts/run_metric_closed_loop.py --confirm-sitl。
本地进程运行 Spring YOLO、轨面投影与中心线拟合，通过 MAVSDK 发送 FRD 机体
横移/偏航速度。机头方向的地面坐标中，轨道在右侧为正；因此正横偏给正向右速度，
正航向误差给正顺时针偏航速度。

## 状态与高度

实时姿态来自 PX4 attitude_euler，实时高度变化来自 position_velocity_ned.down_m。
连接稳定后，在地面静止时用 Gazebo 真值标定一次本地NED原点相对轨面的高程。
飞行中高度 = 标定高程 - down_m。真值的轨道横向偏差与方向不输入控制器。

该起始高程在实体机上需来自已知起飞位置和轨面，或另接测距仪。当前 X500 模型
没有下视测距传感器，本次结果不能等同于实体测距验证。旧版 relative_altitude_m
加连接前高程的方案在首轮试验出现约0.36m差异，已改成本地NED同时刻标定。

Gazebo SITL 直接订阅相机传输消息，保留仿真曝光时间戳和主机回调时刻。评估真值
按仿真时钟插值；PX4姿态与本地NED高度没有可用的同源仿真时间戳，因此按主机接收
时钟对相机回调时刻插值。这消除了直接使用“最新遥测”和PNG落盘的主要错位，但
PX4侧仍是接收时刻近似。每轮先悬停1.5s，识别3帧，至少2帧有效，取横偏与航向
的中位数。

## 观测与控制

鸟瞰前方0至8m、左右各3m、分辨率0.02m/像素。分析前方2至6.5m，保留完整可见
轨道边界，要求足够的有效行和至少2m观测跨度。原左右各2m的窗口在0.4m横偏叠加
10度偏航时曾截断轨道；增大窗口后保存的失败帧恢复有效。

投影前保留掩膜的最大连通区域，避免同一 YOLO 实例中不相连的背景误分割
撑宽左右边界。此操作不填补孔洞，不放宽轨宽、拟合残差或可见范围阈值；
如果主要区域本身分错，仍可能拒绝或输出错误，需要继续用独立真值评估。

每次速度脉冲1s，然后置零并重新悬停。横移增益0.55/s，最大0.12m/s；偏航增益
0.65/s，最大6deg/s。横偏超过0.7m或航向超过15度时拒绝继续动作。连续3轮
识别失败进入保护降落，不沿用旧命令。

连续3轮满足 |横偏|<0.07m 且 |航向|<2度后允许0.10m/s前进；若再偏离，该轮
前进速度归零。完成3次前进脉冲后结束该工况。

两个工况间可施加一次右移及偏航的测试初始化扰动。它显式记录为test_perturbation，
不计为视觉纠偏，也不是线路跟踪策略。原图、鸟瞰和每轮状态/真值/指令写入
captures/metric_closed_loop/<时间戳>。summary.json只报告实际完成的工况。

生成曲线：scripts/summarize_metric_flight.py <结果目录>。
推理、拟合和控制均在同一个伴随计算机模拟进程本地执行；本轮尚未实测树莓派算力。

## 2026-09-16 动态验证

成功记录：captures/metric_closed_loop/20260916_124357。
19/19 轮几何观测有效，两组均完成3次前进脉冲并确认降落，无异常退出。
工况0实际横偏 +0.319 → +0.023 m，航向 +6.18 → +0.21°；
工况1实际横偏 -0.179 → +0.019 m，航向 -4.05 → -0.26°。
这验证了两种误差符号的小偏差闭环，不等于严格完成 ±0.4 m、±10°边界试验。
两组视觉横偏对真值的平均绝对差分别约0.008、0.010 m。

该轮曾用“末帧高度”和整轮结束后的真值比较，得到平均0.137 m差异；后续验证表明
这个比较混入了时刻错位，不应作为高度漂移结论。

同步改进后的成功记录：captures/metric_closed_loop/20260916_213738。
11/11轮有效，完成3次前进脉冲并确认降落。实际横偏 +0.350 → +0.005 m，
航向 +9.85 → +0.05°；视觉横偏对真值平均绝对差0.012 m，航向0.09°。
逐帧PX4投影高度与邻近Gazebo真值相差平均0.024 m、最大0.051 m。因此目前没有
发现十几厘米量级的稳定高度漂移。不过，Gazebo真值查询中点距图片文件时刻仍平均
0.521 s，且图片文件没有曝光时间戳；该结果只能说明悬停/慢速工况的高度足够，
不能代替快速运动下的严格同步或实体测距验证。

当前仍是独立实验入口，没有替换原默认运行入口，也未验证长距离持续跟踪或实体机。
实体机应使用相机硬件时间戳，并优先接入下视测距仪；本地NED可作为短时连续量，
不应单独承担轨面绝对高度。

精确Gazebo时间戳复测：captures/metric_closed_loop/20260916_220216。

脉冲并确认降落。实际横偏 +0.384 → +0.031 m，航向 +10.51 → +0.16°；
视觉相对真值的平均绝对差为0.012 m和0.07°。PX4投影高度相对同仿真时刻真值
平均差0.010 m、最大0.030 m。

反向边界复测：captures/metric_closed_loop/20260916_220901。
33/33帧按仿真时间戳对齐，11/11轮识别有效，完成3次前进并确认降落。实际横偏
-0.358 → -0.008 m，航向 -10.06 → -0.22°；视觉相对真值的平均绝对差为
0.014 m和0.26°，高度平均差0.030 m、最大0.050 m。

两轮合起来验证了约±0.4 m、±10°的两种误差符号，但仍是慢速、直轨、单场景，
不能外推到弯道、强风、纹理变化或连续高速飞行。
