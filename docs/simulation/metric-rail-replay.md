# 轨面校正与米制中心线回放

入口 scripts/replay_metric_rail.py，用已有五帧悬停图和 Gazebo 真值离线回放。
本地 Spring YOLO 使用 retina_masks=True，确保掩膜与相机原始分辨率一致，避免
网络缩放或填充坐标直接进入相机投影。运行不连接飞控。

scripts/audit_rail_dimensions.py 读取 GLB POSITION accessor、沿节点树累计矩阵，
再应用 SDF visual 的旋转与平移。当前模型没有节点 TRS 或稀疏 accessor；本脚本
只针对该模型，不能作为任意 glTF 通用读取器。

测得模型单段长 4.0000004 m、最高轨头平面 Z=0.37164344 m。取顶部 5 mm 顶点带：
两轨内侧间隙约 1.516635 m，轨头中心间距约 1.592584 m。这个顶点带不是铁路
标准规定测量深度的正式轨距，不能宣称模型是 1.435 m 标准轨距。

投影传入高度为 base_link 世界高度减轨面 Z；相机相对机体偏移由 CameraMount
再次计入，避免把机体高度当相机高度。高程修正只适用于当前水平直轨。

MetricRailGeometry 将掩膜投影到 0.02 m/像素的鸟瞰图，选择前方 2 至 6.5 m，
按宽度过滤，拟合中心线 y=a*x+b。输出 b（m，向右为正）、atan(a)（度，向右
为正）以及前方3米的中心偏差。b 是对观测范围外 x=0 的外推，不代表该处有
直接可见的轨道。宽度检查仅为候选过滤，尚不支持岔道或多轨选择。

真值按轨道世界方向 +X 和 Gazebo ENU yaw 构造。水平前向轴为 (cos(yaw),sin(yaw))，
右向轴为 (sin(yaw),-cos(yaw))；因此轨道方向在本坐标的角度等于 ENU yaw，
而不是负 yaw。真值偏差 (body_y-track_y)/cos(yaw)。

报告记录接受/拒绝、模型置信度、拟合支持范围、残差和相对真值误差。红线是
YOLO 中心线、白线是真值。中图按 Z=0，右图按轨面投影。

限制：五张相邻悬停图是小样本自检，使用相近时刻真值而非曝光同步；低残差或
小误差不能证明跨高度、较大姿态、遮挡时的精度。掩膜包络宽度与轨头中心间距
也不是相同物理量，只能比较尺度量级。当前还没有将米制结果送入控制器。
