# Realistic straight railway section

This model packages the four-metre Part 1 straight-track GLB. The active demo
world instances it eight times to form an approximately 32 m straight visual
corridor. No curve or turnout module is included.

The GLB keeps its embedded UVs and four 4096 x 4096 PBR textures. The first demo
uses the world ground plane for collision so the detailed visual mesh does not
add unnecessary physics cost.
